# AI disclosure

websimbotIO was built with an AI coding agent (Arena.ai Agent Mode) working from a
short brief. The database design, the netcode and the renderer were written and tested
in one session; the simulation and the client were both exercised against a live
Supabase project before shipping.

The art is generated at runtime from code — there are no image assets, no stock
graphics and no third-party art in this repository. Fonts are Caveat and Cabin Sketch,
both under the SIL Open Font License, vendored via `@fontsource`.

This is a fan project and is not affiliated with Supabase or with any commercial .io
game.
